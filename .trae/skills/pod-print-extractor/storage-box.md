# 品类：收纳箱（Storage Box）

## 目标尺寸

**1920 × 1280 像素，比例 3:2（横向矩形）。**

## 构图要求

收纳箱是横向承印物，印花会被贴到收纳箱的多个面（前面板 + 左右侧板 + 顶面），最终在收纳箱四周形成一个连续的视觉。

### 拼接机制（关键）

- 印花图案会在收纳箱左右两侧被折叠、拼接，**左右边缘就是物理拼接线**。
- 如果左右边缘的图案杂乱、有半个元素、或左右无法自然衔接，收纳箱成品会显得粗糙、难看。
- 因此必须严格控制左右边缘的视觉处理。

### 左右边缘处理（首要要求）

按优先级处理左右边缘：

1. **首选：左右两边留白**
   - 画面主体居中或偏左偏右均可，但**左右两侧各预留 8%–15% 画布宽度的安全留白区**。
   - 留白区不得放置任何主体元素、重要装饰、文字。
   - 留白区可以是纯背景色（与图案背景色一致），也可以是极淡的辅助纹理。
   - 留白区的作用是：即使拼接处有微小错位，也不会有元素被切掉。

2. **次选：左右自然衔接**
   - 如果原图本身就是满版/连续图案，且左右边缘的元素能够自然连接（如连续的花枝、几何重复、无缝纹理），允许元素延伸到左右画布外。
   - 但延伸到画布外的元素必须能"接得上"——即左边缘延伸出去的部分，应当能与右边缘延伸出去的部分在拼接后形成连续完整的元素。
   - 如果无法判断能否衔接，**回退到留白方案**。

3. **严禁：左右边缘出现半个元素**
   - 左右画布边缘不得出现被截断的主体（半个人、半个动物、半个几何主体、半朵主花）。
   - 如果原图中靠近左右边缘有主体元素，应将其整体移入画布内部，或调整位置使其完整。

### 横向构图

- 横向矩形 3:2，主视觉沿横轴组织。
- 主体居中或均衡分布在横向空间内。
- 不要因为横向而把竖构图主体强行横向拉伸。

### 上下边缘

- 上下边缘的要求相对宽松，但仍遵循 base.md 第七节：不要出现被截断的主体。
- 如果收纳箱顶面也印花，上下边缘按"自然延伸或留白"处理，避免半个元素。

## 风险规避

- 不要把视觉最重、最复杂的元素堆在左右边缘——那是拼接缝，越简单越安全。
- 不要在左右边缘放文字（拼接错位会让文字变成乱码）。
- 不要让图案在左右边缘出现明显的高对比度色块分界（拼接后会产生竖向接缝线）。
- 如果原图的视觉信息量集中在中央，左右本身就有留白，则保持这种自然留白，不要为了"填满画布"而强行往左右添加元素。
