# 品类：伞（Umbrella）

## 目标尺寸

**1920 × 1920 像素，比例 1:1（正方形）。**

## 构图要求

伞面印花是中心对称或中心放射性的载体，最终图案会被裁切、拼接贴到伞面上，所以图案的中心点必须严格对准画布几何中心。

### 中心校正（关键）

- 原图是商品实拍图，截图本身可能偏移，**图案的视觉中心不一定落在截图中心**。
- 必须先识别图案真正的中心点（放射源 / 主视觉锚点 / 对称轴交点），再据此重新居中。
- 校正后整个画布围绕该中心重新组织，不允许"看似居中、实则偏左/偏右"。
- 如果原图只是局部截图，根据可见的放射方向、元素排布、对称线索推断真正的中心位置。

### 中心放射性图案

如果图案属于中心放射式（花卉、曼陀罗、对称几何、放射状装饰等）：

- 以放射源为绝对中心，向四周均匀展开。
- 如果原图的放射不完整（被截断的部分），按对称规律补全。
- 放射的角度间距、元素大小遵循原有节奏，不要随意增减分支数量。

### 满版 / 连续图案

如果属于满版连续图案（无中心），按 base.md 第六节处理，不强求居中，但整体视觉重量要均衡。

## 边缘

- 正方形画布的四个边缘允许元素自然延伸到画布外（满版图案）。
- 但不得出现"被切掉的主体"（base.md 第七节同样适用）。
- 中心放射性图案的四个角可以留白，也可以填满，取决于原图风格——保持原图的边缘处理方式。

## 风险规避

- 不要因为 1:1 而把原本是横向的放射图案强行压成正方形。
- 不要把放射源移到角落。
- 不要让放射分支在画布边缘突然中断——要么完整收束，要么自然延伸至画外。
